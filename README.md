# Сэтгэлийн Толь

Сэтгэл зүйн үйлчилгээний вэб сайт (frontend). Хэрэглэгч бүртгүүлж нэвтрээд, багцаа төлж, сэтгэл зүйчтэйгээ өдөр бүр мессежээр харилцана. Мөн өөртөө туслах хичээлүүд, сэтгэл гутрал (PHQ-9), түгшүүрийн (GAD-7) тест үнэгүй.

## Боломжууд

- **Бүртгэл, нэвтрэлт:** нэр, утас, имэйл, нууц үгээр бүртгүүлэх, нэвтрэх, гарах
- **Багцууд:** 7 хоног, 1 сар, 3 сар. Хэрэглэгч дансаар төлөөд «Төлбөр төлсөн» гэж мэдэгдэнэ
- **Чат:** багц идэвхтэй үед сэтгэл зүйчтэйгээ мессежээр харилцана
- **Сэтгэл зүйчийн самбар:** хэрэглэгчдийн жагсаалт, хариу бичих, багц идэвхжүүлэх, сунгах, зогсоох, үнэ болон дансны тохиргоо
- **Хичээлүүд:** 5 сургалт, 18 хичээл, ахиц хадгалагдана
- **Тестүүд:** PHQ-9, GAD-7. Өөрийгөө гэмтээх бодлын асуултад яаралтай тусламжийн мэдээлэл гарна
- **Өдөр тутмын хэрэгсэл:** сэтгэл санааны тэмдэглэл, амьсгалын дасгал
- Гар утсанд тохирсон, шөнийн горимтой

## Ажиллуулах

Сервер, build шаардлагагүй. Энгийн статик сервер ашиглана:

```bash
python3 -m http.server 8000
# эсвэл: npx serve .
```

Дараа нь `http://localhost:8000` нээнэ. `index.html`-ийг файлаар шууд нээвэл JavaScript модуль ажиллахгүй тул сервер ашиглана уу.

GitHub Pages дээр байршуулах: репоны **Settings → Pages → Branch: main / (root)**.

## Демо горим

Одоогоор сервер холбогдоогүй. Бүх өгөгдөл (бүртгэл, чат, багц) хөтөчийн `localStorage`-д хадгалагдана.

- Сэтгэл зүйчийн демо бүртгэл: `psy@demo.mn` / `demo123`
- Нэвтрэлт таб бүрт тусдаа. Нэг табд хэрэглэгчээр, нөгөөд сэтгэл зүйчээр нэвтэрвэл чат хооронд нь шууд солигдоно.
- Өөр төхөөрөмж, хөтөч хооронд өгөгдөл дамжихгүй. Жинхэнэ хэрэглээнд сервер заавал хэрэгтэй.

## Бүтэц

```
index.html          Хуудасны бүтэц
assets/style.css    Загвар (өнгө, үсэг, шөнийн горим)
assets/app.js       Хуудасны логик: хичээл, тест, багц, чат, самбар
assets/api.js       Өгөгдлийн давхарга (одоо демо, localStorage)
```

## Дараагийн алхам: сервер холбох

`app.js` өгөгдөлтэй зөвхөн `api.js`-ээр дамжиж харьцдаг. Сервер холбохдоо `api.js`-ийг ижил функцуудтай шинэ хувилбараар солино:

| Функц | Үүрэг |
| --- | --- |
| `onAuth(cb)` | Нэвтэрсэн хэрэглэгч өөрчлөгдөхөд `{uid, name, phone, email, isAdmin}` эсвэл `null` дамжуулна |
| `register({name, phone, email, password})`, `login(email, password)`, `logout()`, `resetPassword(email)` | Бүртгэл, нэвтрэлт |
| `watchConfig(cb)`, `saveConfig(data)` | Үнэ, дансны тохиргоо |
| `watchChat(uid, cb)`, `saveChat(uid, data)`, `watchAllChats(cb)` | Хэрэглэгчийн чатын мэдээлэл (нэр, утас, төлбөрийн мэдэгдэл) |
| `watchSub(uid, cb)`, `setSub(uid, data)`, `watchAllSubs(cb)` | Багц: `{plan, until, activatedAt}` |
| `watchMessages(uid, cb)`, `addMessage(uid, {from, text, at})` | Мессеж |

`watch…` функцууд бүгд unsubscribe функц буцаана. Firebase (Auth + Firestore) эсвэл Supabase тохиромжтой. Сервер талд дараах дүрмийг заавал хангана:

- Хэрэглэгч зөвхөн өөрийн чат, мессежийг уншина
- Багцыг (`subs`) зөвхөн сэтгэл зүйч өөрчилнө
- Багц идэвхгүй хэрэглэгч мессеж илгээх боломжгүй
